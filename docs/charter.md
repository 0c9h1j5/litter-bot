# D02 팀 차터 — 체육관 정리 로봇 팀

D02 · 팀 차터 · 작성 최현준(PM) · 검토 최현준 · 상태 작성 · v0.3 · 관련 [00-기획안.md](00-기획안.md)

## 목표 한 줄
대관과 대관 사이 실내 체육관의 코트·벤치 주변에서 생수병·캔·컵을 집고(핫스폿 순회) 마루 먼지를 극세사 패드로 미는(직선 훑기) 로봇을 MuJoCo 시뮬레이션(Stretch 3)으로 입증하고, 메카넘 차 + 3D 프린트 집게 + 모터 없는 패드 축소판으로 실내 마루에서 시연한다.

## 범위
| 구분 | 내용 |
| --- | --- |
| 한다(In) | 핫스폿(벤치 구역 → 코트 구석 → 창문틀) 순회로 세운 생수병·캔·컵을 집어 로봇에 실은 바구니에 넣기, 창문틀(높이 1.0 m 가정) 위 집기(시뮬만), 극세사 패드로 코트를 직선 줄로 밀고 닦은 면적 % 계산, 깊이 돌출 + 색 인식, 공·가방·의자 우회, 사람 1 m 안이면 멈춤, 소지품 오인 방지 규칙, 결과 보고(수거·커버리지·확인 필요·건너뛴 칸), 반복 평가(시뮬 10회·실물 5회)와 3전략 비교(핫스폿 순회·지그재그·찾아가기), 실물 실내 2 m × 2 m 표적 3개 + 패드 훑기, 현장 검증(계수·사람 기준선·미끄럼 전후·Mom Test 인터뷰) |
| 확장(남는 시간) | 모드 2 중 떨어진 병 집고 복귀, 코트 라인 카메라 위치 보정, 누운 병·캔, 먼지 제거량 정량화, 물기 칸 건너뛰기, 실물 우회 |
| 안 한다(Out) | 관람석(계단식)·계단·로비·실외, 경기 중 운행, 젖은 바닥·쏟은 음료, 테이프·밴드·껌·휴지, 소지품(가방·신발·공·물이 찬 병) 수거, 습식 청소, 실물의 창문틀, 학습형 검출기, SLAM, 실제 Stretch 구동, 실제 체육관 무인 운행(시설 동의·안전 확인 전제), 꽁초·눈 치우기(다른 현장 버전 v1.1) |

## 플랫폼 결정
- 시뮬레이션: MuJoCo Menagerie의 Hello Robot Stretch 3를 그대로 쓴다. 근거: 바닥까지 닿는 팔 + 리프트(모델 0~1.1 m, 그리퍼 약 1.22 m까지 실측)로 '바닥 + 창문틀'을 한 로봇이 한다. 장면은 `scenes/gym_v0.xml`(농구 코트 일부 5 m × 3 m)에서 시작한다. 위험: 집기 불안정 → 12/04까지 '들어 3초 버티기'가 안 되면 '닿으면 붙기'(weld)로 단순화한다. 패드는 충돌 없는 판정 영역으로 둔다(먼지는 흉내 내지 않음).
- 실물: 메카넘 바퀴 차(고무·우레탄 롤러, 마루 긁힘 방지) + 3D 프린트 집게(서보 2개) + 모터 없는 극세사 패드(바퀴 앞, 밀대 선행) + 앞 거리 센서 2개·범퍼로 축소판 1대. 체육관 마루와 비슷한 실내 평탄 바닥에서 시연한다(집 바닥은 코팅 마루와 다를 수 있음). 12/09까지 정지 표적 5번 중 3번을 못 집으면 '원격 조종 집기 + 자율 패드 훑기'로 줄인다.
- 운영 전제: 4주는 시뮬·실내 시연이고, 실제 체육관 운행은 시설 관리 주체의 동의와 안전 확인을 전제로 한다.
