# D02 팀 차터 — 쓰레기 줍는 로봇 팀

D02 · 팀 차터 · 작성 최현준(PM) · 검토 최현준 · 상태 작성 · v0.1

## 목표 한 줄
매일 아침 가게 앞 평평한 바닥의 작은 쓰레기 줍기를 이동형 로봇팔이 맡는 것을 MuJoCo 시뮬레이션으로 입증하고, 3D 프린트 축소판 실물로 시연한다.

## 범위
| 구분 | 내용 |
| --- | --- |
| 한다(In) | 카메라 색 인식으로 쓰레기 찾기, 장애물 피해 이동, 집기, 쓰레기통에 넣기, 반복 평가(10회 평균), 실물 축소판으로 캔·컵 집어 넣기 시연 |
| 안 한다(Out) | 보도블록 틈·턱·경사(요철 1 cm·경사 3° 초과), 비·젖은 쓰레기, 비닐·종이·깨진 유리, 딥러닝 인식, 자기 위치 추정(SLAM), 사람이 다니는 상황, 실제 Stretch 로봇 구동 |

## 플랫폼 결정
- 시뮬레이션: MuJoCo Menagerie의 Hello Robot Stretch 3를 그대로 쓴다. 근거: 바닥까지 닿는 팔과 이동 바닥이 함께 있다. 위험: 집기 불안정 → 집기 1회를 먼저 확인하고, 정한 날짜까지 안 되면 '닿으면 붙기'(weld)로 단순화한다.
- 실물: 메카넘 자동차 + 3D 프린트 집게 팔(서보)로 축소판을 만든다. 새로 만드는 만큼 일이 늘어나므로 평평한 실내 바닥, 캔·컵 크기만 다룬다.
