**기획안에 '이미 정한 것'으로 적혀 있으나 따로 날짜·결정자 기록이 없는 것** (2026-11-23 기획안 v1.2~v1.3에 처음 적힘): 밀대·집게 모두 4주 필수, 분실물은 줍지 않고 알림, 로봇에 통 싣기 유지, 병·캔 = 핫스폿 순회 / 밀대 = 직선 훑기, 실물 = 메카넘 유지(궤도는 이 현장에 필요 없음).

**아직 정하지 않은 것:** 기획안 15-2 (현장 검증 체육관, 실제 체육관 촬영 여부, SO-ARM101 결제·주문 시점).
