# 현장 계수표 — 경기 직후 한 장

P02 · 현장 계수표 · 기획안 [13장](00-기획안.md) · 11/24(화) ~ 11/30(월) · 같은 칸의 CSV: `logs/field/field_count_template.csv`

**규칙:** 경기 1회마다 아래 한 장(= CSV 한 줄). 체육관 2~3곳 × 경기 직후 3회 이상. 사진에 **사람 얼굴·이름표·차량번호가 나오지 않게**. 시설 안 촬영은 관리자에게 먼저 묻는다. 이름·연락처는 적지 않는다.

---

**1. 언제·어디**

- 날짜: ____ / ____  
- 체육관 종류: ☐ 학교 ☐ 구민 ☐ 사설  · 체육관 기호(A/B/C): ____
- 경기 끝난 시각: ____ : ____  · 센 시각: ____ : ____
- 다음 대관까지 빈 시간: ____ 분 (모르면 비움)
- 벤치 옆 수거함·쓰레기통: ☐ 있음 ☐ 없음

**2. 위치별 개수** (빈 병·캔·컵만. 물이 찬 병은 맨 아래 칸)

| 벤치 구역 (위·아래) | | | | |
| 코트 구석 | | | | |
| 창문틀 | | | | |
| 코트 안 | | | | |
| 기타 (로비·관람석 아래 등, 어디인지 메모) | | | | |
| 물이 찬 병 (어디든) | | — | — | — |

기타 예: 테이프·밴드, 휴지, 과자 봉지 (적은 품목을 메모에)

**3. 잰 것**

- 사람 정리 시간 (병·캔·컵 전부 주워 통에 넣기, 스톱워치): ______ 초
- 사람 밀대 시간 (했으면, 민 구역 대략 ___ m × ___ m): ______ 초
- 창문틀 높이 (바닥 → 윗면, 줄자): ______ cm · 깊이 ______ cm
- 흰 천 1 m 먼지 사진: ☐ 코트 중앙 ☐ 벤치 앞 · 사진 번호 ______
- 미끄럼 당김 (했으면, 13-5 A): 밀대 전 ______ / 후 ______ (kgf, 5회 평균)

**4. 관리자 한 줄 메모** (과거 사실만 — "지난번엔 누가 치웠나", 의견·칭찬은 따로 표시)

- ________________________________________________

**5. 사진 번호:** ________ (쓰레기 위치, 반입 규정 게시물)
