# 현장 계수표 — 경기 직후 한 장

P02 · 현장 계수표 · 기획안 [13장](00-기획안.md) · 11/24(화) ~ 11/30(월) · 같은 칸의 CSV: `logs/field/field_count_template.csv`

**현장 데이터 (실측 + 추정):** 1차 근거 = 현장 관찰 기반 추정(체육관 약 10곳·1년, 기획자 직접 이용) — `logs/field/2026-11-23_주인회고.md`, 추정 데이터셋 `logs/field/field_estimate_v1.csv`. 회고 요지: 경기당 생수병 1 + 과자 봉지 2, 먼지 뭉치·흙먼지·셔틀콕 깃털·분실물(교복), 쓰레기는 벤치 쪽·깃털은 코트 위, 쓰레기통은 입구 쪽, 사람 5~10분 / 밀대까지 10~20분. 이 표는 그 회고를 **확인하거나 뒤집는** 계수다.

**실측 추가 3단계:** ① 경기 1회를 `logs/field/field_count.csv`에 **한 줄 추가**(`source=field_count`) → ② `uv run python scripts/field_summary.py` **실행** → ③ [03-현장데이터-요약.md](03-현장데이터-요약.md) **요약이 갱신**된다(유형별 실측 3건 이상이면 실측값만, 1~2건이면 추정과 섞어 쓴다). HTML은 `uv run --with markdown python docs/build_html.py`로 다시 만든다.

**규칙:** 경기 1회마다 아래 한 장(= CSV 한 줄). 체육관 2~3곳 × 경기 직후 3회 이상. 사진에 **사람 얼굴·이름표·차량번호가 나오지 않게**. 시설 안 촬영은 관리자에게 먼저 묻는다. 이름·연락처는 적지 않는다.
