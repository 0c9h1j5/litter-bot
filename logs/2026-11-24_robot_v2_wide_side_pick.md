# 2026-11-24 robot_v2 기본 차체(wide_side) — 넓은 차체 + 팔 옆에 거는 통, 넣기 실측

주인 결정(2026-11-24, [decisions.md](../docs/decisions.md)): 쓰레기통 = **팔 옆에 거는 통**(묻힌 통 0/9 취소), 차체 = **넓은 차체(직접 제작, 38~40 cm급)**.
그래서 `scripts/build_robot_v2.py`의 기본(`scenes/robot_v2.xml`, `gym_v2.xml`)을 `wide_side`로 바꿨다. 예전 기본(X3 + 묻힌 통)은 `robot_v2_x3.xml`, `gym_v2_x3.xml`로 이름만 바뀌었다(내용 같음).

- 환경: MuJoCo 4.0.1, macOS. 측정 `uv run python src/checks/robot_v2_measure.py wide_side pick` / `... wide_side trials tip` (스크립트는 고치지 않음 — 크래들 접기는 아직 X3용 `STOW_V2`를 씀)
- 출력 원문: 아래 '출력' 절

**한 줄:** 넓은 차체에 옆 통을 단 모델은 **한 번(가운데)은 넣었지만 9곳 시험은 0/9**다. robot_v1의 8/9는 X3 차체·깊이 10 cm 통에서 잰 값이라 넓은 차체로 그대로 옮겨지지 않았다 → **확인 필요**.
- 같은 가운데 자리(0, 0)가 `pick` 단독에서는 성공, `trials` 안에서는 실패했다. `trials`는 첫 자리(−2, −2 cm)에서 고른 통 위 자세를 IK 씨앗으로 다시 쓰고, 옮기는 길은 관절 직선 보간이다(`robot_v2_measure.py` pick). 그래서 **놓는 길(경로 계획)에 따라 결과가 바뀌는 것으로 보인다** (원인 확인 안 함 — 추정).
- 통을 10.5 cm로 깊게 하고 옆으로 1.5 cm 더 뺀 시험도 0/9였다. 이 시험의 통 바닥은 앞바퀴 높이(0.065 m)보다 낮아 실물로는 바퀴와 겹친다(보기용 바퀴라 시뮬에서는 부딪히지 않음).
- 크래들 접기 자세는 X3용 `STOW_V2`다. 넓은 차체용 자세 `STOW_V2_WIDE`(옆 0 mm, 최고 0.352 m)는 스크립트에 상수로만 넣었고 측정에는 아직 쓰지 않았다.

**다음에 할 것 (주인 결정 아님, 측정 작업):** 넓은 차체용 놓는 길(통 위로 수직으로 가져가는 경로)과 크래들 자세로 9곳 다시 재기. 통 자리(옆 거리·높이·깊이)를 바꿔 가며 비교.
