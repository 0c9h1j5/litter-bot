# 2026-11-23 주인 회고 — 체육관 약 10곳 비교 (기억 기반)

- 종류: **주인 회고(n≈10곳)**. 최근 1년 안에 다닌 체육관 약 10곳(학교·구민·사설)을 떠올려 비교한 요약이다.
- **직접 센 계수가 아니다.** 기억에 기반한 요약이므로 기획안에서는 '1차 근거이자 가설'로만 쓰고, 11/24~11/30 계수(`docs/02-현장계수표.md`, `logs/field/field_count_template.csv`)로 확인한다.
- 기록: 주인 진술을 그대로 옮겼다(정리만, 숫자 바꾸지 않음).

## 진술 (그대로)

| 항목 | 주인 회고 |
| --- | --- |
| 경기 1회 뒤 평균 | 생수병 1개, 과자 봉지 2개, 먼지 뭉치, 바닥 흙먼지, 배드민턴 셔틀콕 깃털 조각, 학생 교복(분실물) 등. 관리가 아주 잘 된 곳을 빼면 대체로 비슷 |
| 위치 | 쓰레기는 주로 벤치 쪽. 셔틀콕 깃털은 코트 위에 많음 |
| 쓰레기통 | 보통 입구 쪽에 둠(벤치와 떨어져 있음) |
| 다음 대관까지 | 사설은 오후에 빠듯할 때가 있고 오전은 여유. 학교는 수업에 따라 다름. 구민은 다음 대기자가 일찍 와서 기다리는 편. 구청 시설은 비교적 관리가 잘 되지만 큰 쓰레기가 있을 때가 있음 |
| 사람 정리 시간 | 쓰레기만 가져가면 5~10분, 밀대로 바닥 청소까지 하면 10~20분 |

## 이 회고로 바뀐 가설 (기획안 v1.3)

| 가설 | 확인 방법 (11/24~11/30) |
| --- | --- |
| 큰 쓰레기는 경기당 생수병 1개 + 과자 봉지 2개 수준 → 병·캔·컵만 세면 중단 기준 K-1(경기당 1개 미만)의 **경계값** | 계수표 위치별 생수병·캔·컵·과자 봉지 개수, 경기 3회 이상 평균 |
| 사람 시간은 밀대 쪽이 더 크다(쓰레기만 5~10분 → 밀대까지 10~20분) → **밀대 = 주 기능, 집게 = 보조** | 사람 기준선 스톱워치(쓰레기만 / 밀대까지 따로) |
| 바닥 쓰레기는 먼지 뭉치·흙먼지·셔틀콕 깃털 → 패드 대상 | 흰 천 1 m 사진, 깃털·먼지 뭉치 정도(0~3) |
| 분실물(교복 등)이 코트에 남는다 → 줍지 않고 사진·알림 | 계수표 분실물 칸 |
| 쓰레기통이 입구 쪽이라 벤치에서 멀다 → 로봇에 통 싣기 유지 | 계수표 쓰레기통 위치 칸, 사진 |
| 대관 사이가 짧다(구민은 대기자가 기다림) → 짧은 모드 필요 | 계수표 다음 대관까지 분, 인터뷰 질문 4 |
